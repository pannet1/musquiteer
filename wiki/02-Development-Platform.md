## Programmable drone: LiteWing ESP32-S3

**Proposed starting platform:** LiteWing ESP32-S3 programmable micro-drone.

| Detail | Value |
|---|---|
| Type | Development platform (not a finished autonomous product) |
| Indicative listed price | ~₹3,999 |
| Motors | Four |
| Intended use | Indoor flight, programmable |

### Before ordering, confirm with the seller:

- Current price
- Package contents (flight controller, four motors, propellers, frame, battery, charger, guards)
- Battery and charger inclusion
- Payload capacity
- Firmware access
- Supported control interfaces

---

## Camera and AI board: FireBeetle 2 ESP32-S3

**Indicative listed price:** ~₹1,949

| Detail | Value |
|---|---|
| Includes | Camera and wireless connectivity |
| Relationship to LiteWing | Separate board — **not confirmed** as a plug-and-play upgrade |
| Role | Experimental starting point for embedded-vision experiments |

### Before purchasing, confirm:

- Weight
- Dimensions
- Power requirements
- Camera interface
- Software support
- Communication method
- How camera video can be accessed by AI software
- Whether frame rate is adequate

### Capability caveat

The ESP32-S3 can support **lightweight embedded-vision experiments**, but dependable recognition of tiny, fast-moving mosquitoes **may require a more capable AI computer**. Treat this board as an experimental starting point, **not** a proven mosquito-recognition solution.
